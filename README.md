# HD-Upscale 高清放大 Skill 🎨

阿辉自己封装、免费分享的一个 AI 技能。装上之后，只要一句话，就能把模糊、小尺寸的图片重新高清绘制并放大，最终给你一张高清 PNG 成品，外加一个能拖动对比的前后效果网页。

不用装软件、不用手动调参数：上传图片 → 说一句话 → 等收成品。

**⬇️ 一键下载安装包：[hd-upscale.zip](https://github.com/yhhgongzuo/HD-Upscale/releases/latest/download/hd-upscale.zip)**

## 🎯 这个 Skill 能帮你解决什么

- 把模糊图、小图重新高清重绘，再放大、增强画质
- 输出 PNG 高清成品，**豆包平台最终可达 4K**
- 自动生成前后效果对比网页，拖动滑块就能看到变化

适合谁：手里有一堆模糊小图、老图、电商素材图，想快速变高清又不想折腾 PS 的朋友。

## 🧠 先搞懂一件事：这不是简单把图拉大

普通放大只是把像素硬拉开，图会越来越糊。这个 Skill 的流程是：先用生图模型**参考原图重新高清绘制**（细节是重新画出来的，不是凭空拉大），再把生成图宽高各放大两倍，最后用固定的 ART 预设做画质增强。整个过程只有一次 AI 重绘，不是反复烧额度的多次超分。

## 🖥️ 支持平台

这个技能在哪个 Agent 上都能装，但不同平台内置的生图模型不一样，最终出图的尺寸和效果差别很大。安装前先看这张表：

| 平台 | 出图效果 | 建议 |
|---|---|---|
| 豆包工作（首选） | 内置生图模型，最终可出 4K 图片 | ✅ 最推荐，一步到位，不用折腾 |
| Codex（GPT） | 可以用，出图尺寸约 2K–3K，比豆包小一圈 | 第二选择 |
| WorkBuddy | 内置混元生图模型，实测效果差 | ⚠️ 不建议直接用 |
| 其他 Agent 平台 | 取决于你自己接的生图模型 | 需要动手接 API |

💡 不懂接口、不会接 API 的朋友，直接用豆包就行，别在其他平台上浪费时间。

如果 WorkBuddy 或其他平台一定要用，需要自己另外接一个生图接口，推荐这三个模型：**Banana（香蕉）、豆包 Seedream 5.0pro、GPT Image 2.5**，其他模型效果没有保障。

优先级一句话：**豆包 > Codex > 其他平台（需自己接生图模型）**。

💡 **必须切换到「工作模式」**：不管是豆包、Codex 还是 WorkBuddy，都必须先切换到能接管电脑、执行任务的「工作模式」再运行。普通对话模式只能聊天，Skill 不会生效。

## 📦 安装与使用（三步上手）

核心就是：导入文件 → 自动装好 Skill → 发图下指令。

### 第一步：切换到工作模式

在你的 AI 工具里切换到「工作模式」，确认它具备操控电脑、执行任务的权限。

### 第二步：下载 Zip，整个发给 AI 自动安装

下载安装包：**[hd-upscale.zip](https://github.com/yhhgongzuo/HD-Upscale/releases/latest/download/hd-upscale.zip)**

把整个 ZIP 直接发给你的 AI（**不要手动解压**），附上这句话：

> 请安装这个技能

等待安装完成即可。

### 第三步：上传图片，说「用阿辉的高清放大」

1. 上传一张需要处理的图片
2. 对 AI 说：**用阿辉的高清放大**
3. 等待处理，你会收到两个文件：
   - **前后效果对比网页**：拖动滑块查看变化
   - **高清放大成品 PNG**：点击下载保存

## ⚠️ 注意事项 & 常见问题

- **这个 Skill 收费吗？** Skill 本身免费分享，一分不收。生图会产生费用，按你所用平台的规则走，消耗的是你自己账号的生图额度，与作者无关。
- **安装包要解压吗？** 不要自己解压，整个 ZIP 直接发给 AI 就行。
- **安装时提示失败怎么办？** 你的 AI 必须支持「参考图生图」和运行程序，否则装不了。AI 会明确告诉你失败原因，这不是安装包的问题；其他平台没接生图接口的，先按上面的平台表接好接口再装。
- **安装包会过期吗？** 不会。现在跑不了的平台，先收藏教程和安装包，等模型能力跟上后再用。
- **不同平台出图尺寸为什么不一样？** 最终尺寸取决于平台内置（或你自己接的）生图模型能力，豆包可到 4K，Codex 一般 2K–3K，这是模型侧的差异，不是 Skill 设了限制。

├── assets/
│   ├── resources.json          # 各平台离线资源的官方地址、SHA-256 与体积
│   ├── preview/template.html   # 午夜蓝对比页模板（滑动、缩放、全屏）

├── MANIFEST.sha256.json        # 安装包完整性清单
