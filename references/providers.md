# 生图能力适配

能力发现由宿主 Agent 完成，不能由本地 Python 脚本猜测宿主所有工具。

1. 查实际工具列表/已配置连接器，查阅对应工具参数。区分参考图编辑与仅文生图。优先复用用户已配置的接口，不安装无关平台插件，不搜集本机其他应用密钥。
2. 确认参考图输入形式（本地文件、附件 ID、base64 或 URL）、返回形式（本地文件、下载链接或任务 ID）、可用模型及权限。没有公开可选模型时使用工具自身支持的高质量能力，不虚构模型名。
3. 模型质量优先于像素数。在有文档依据的可用模型中选择适合原图保真增强的最高质量项；同一模型用最高质量参数及保持比例的最大合法尺寸。固定尺寸枚举、总像素上限、步长/倍数、宽高比限制均以当前提供方规则为准，不套用豆包尺寸公式。若无法保持比例，说明限制，不裁切、拉伸或加白边冒充成功。
4. 模型/权限不可用可换下一个已核实可用模型；尺寸不支持可在同一模型内选次大合法尺寸。每个模型与尺寸组合最多一次，最多三次实际提交。内容审核失败不换模型绕过；账户无额度时说明问题。超时/状态不明先查原任务，避免重复付费。
5. 原生工具缺失时，请用户提供接口地址、文档、可用模型、鉴权配置方式。使用提供方真实协议，包括官方 SDK、兼容接口或自定义接口；不能假定任何 API 都接受相同的 images/edits 参数。不在分享包中保存用户密钥。
6. 保留提供商真实错误与降级情况，以简单语言反馈。不能宣称所有用户拥有同一模型或质量档。

豆包分支完全使用 `assets/legacy-doubao/SKILL.md` 与原提示词的生成配置；此文件的通用模型选择不覆盖豆包分支。
